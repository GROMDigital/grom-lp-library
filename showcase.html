LP library showcase

The library is 22 reusable block archetypes (blocks/*--*.html) across 11 section types, 4 themes, and one shared motion layer, not a fixed set of finished pages. These four starters are sample compositions built from that system, each pairing one theme with one deliberate set of section archetypes, so this page is a visual sanity check of four possible outcomes, not a gallery of every combination. Each frame lazy-loads the starter's own index.html at laptop width. Use "open full" to view a starter on its own, at real size. See CATALOG.md for every archetype and BUILD-GUIDE.md for how to compose a new page from them.
