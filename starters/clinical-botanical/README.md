# Starter: clinical-botanical

Single-file, fully filled landing page assembled from the `reference/lp-library` block library on the **clinical-botanical** theme (`themes/clinical-botanical.css`, porcelain/deep-green with mint and blush accents, gradient CTAs, soft ambient glows, Fraunces + Hanken Grotesk). Block order: `hero-botanical -> offer-deposit -> steps-ghost -> why-us -> reviews -> founder -> booking-widget -> faq-accordion -> sticky-cta -> footer`. The `_contract.css` + `clinical-botanical.css` tokens are inlined into one `<style>` in the document head (contract first, theme second so it overrides). The theme's Google Fonts `@import` is hoisted to the very top of that combined `<style>`, ahead of both token blocks, since a CSS `@import` is only honoured when it precedes every other rule in the stylesheet. The hosted-loader head-tracking snippet sits at the very top of the file inside a single HTML comment, ready to paste into the page's tracking code settings.

**Sample identity (fictional):** Verdance Skin Studio, an advanced facials and skin renewal studio in Charlton, SE London, led personally by Elise Marchetti, Skin Specialist, 4.9 from 160 reviews, facials from £180 (was £240), `CLIENT_KEY = "verdance-skin"`. The Meta Pixel ID is the literal placeholder `REPLACE_WITH_PIXEL_ID` (marked inline), the booking-worker URL is the placeholder `https://your-booking-worker.invalid` (marked inline, using the IANA-reserved `.invalid` TLD so it is unregistrable), and both hero/founder photos are placeholder SVG data URIs (marked inline) standing in for real studio photography. No AHPRA-regulated outcome or results language is used; copy stays in process/care terms ("aftercare guidance," "considered approach") and avoids words like "permanent" or "cure."

**Deposit handling (the theme's distinguishing mechanic):** this is the first starter built around the deposit-led `offer-deposit` block. The hero's `hero-botanical` chip and CTA-adjacent copy both carry the exact line "£40 deposit comes off the price," and `offer-deposit`'s dedicated deposit-line row (with its own icon and accent token, `--deposit-accent`) restates it as "£40 deposit, comes straight off the price of your facial," with the fine-print note spelling out the mechanic plainly (deposit deducted from the £180 treatment price, confirms the appointment). The FAQ's first question exists specifically to remove any doubt that the deposit is separate from the treatment price.

**Rich-block treatment:** `hero-botanical` and `offer-deposit` are the two "rich" blocks in the library, the only ones consuming the theme's decorative tokens (`--cta-grad-a`/`--cta-grad-b` gradient CTA, `--shadow-cta`, `--glow-1`/`--glow-2` ambient hero glows, `--ghost-color` for `steps-ghost`'s oversized faded step numerals). Combined with Fraunces' italic serif emphasis on the hero headline's `<em>Considered</em>` and the theme's pill-shaped buttons (`--r-pill: 999px`), the page reads as the calmest, most botanical-clinical of the four starters rather than the editorial, price-led, or clinical-trust treatments already in the library.

**To reuse for a real client:** clone this folder, run the FILL-GUIDE against the new client's identity, then swap the three placeholders: `CLIENT_KEY` in the head-tracking comment, `REPLACE_WITH_PIXEL_ID` with the client's real Meta Pixel ID, and the booking-worker URL with the client's real `grom-booking-worker` deployment, then replace the placeholder images with real photography.
