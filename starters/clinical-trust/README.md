# Starter: clinical-trust

Single-file, fully filled landing page assembled from the `reference/lp-library` block library on the **clinical-trust** theme (`themes/clinical-trust.css`, cool/sage/credibility-led, grotesque sans, tighter radii, hairlines). Block order: `hero-split -> why-us -> how-it-works -> founder -> reviews -> offer-card -> booking-widget -> faq-accordion -> sticky-cta -> footer`. The `_contract.css` + `clinical-trust.css` tokens are inlined into one `<style>` in the document head (contract first, theme second so it overrides). The hosted-loader head-tracking snippet sits at the very top of the file inside a single HTML comment, ready to paste into the page's tracking code settings.

**Sample identity (fictional, AHPRA-safe):** Northside Cosmetic, an injectable and skin clinic in Chatswood NSW, led personally by Dr. Hannah Pryce (MBBS), 4.9 from 210 reviews, `CLIENT_KEY = "northside-cosmetic"`. The Meta Pixel ID is the literal placeholder `REPLACE_WITH_PIXEL_ID` (marked inline), the booking-worker URL is the placeholder `https://your-booking-worker.invalid` (marked inline), and both hero/founder photos are placeholder SVG data URIs (marked inline) standing in for real clinic photography.

**No-price handling:** this is an injectable clinic that never shows a procedure price. Both `hero-split` and `offer-card` carry an `{{offer_price}}` slot; here they are filled with "Complimentary Consultation" instead of a dollar figure, and the offer-card is framed entirely around what the consultation includes (the conversation, assessment, and personalised plan) rather than a treatment cost. Copy avoids outcome guarantees and words like "permanent" or "cure," consistent with injectable-safe messaging.

**To reuse for a real client:** clone this folder, run the FILL-GUIDE against the new client's identity, then swap the three placeholders: `CLIENT_KEY` in the head-tracking comment, `REPLACE_WITH_PIXEL_ID` with the client's real Meta Pixel ID, and the booking-worker URL with the client's real `grom-booking-worker` deployment, then replace the placeholder images with real photography.
