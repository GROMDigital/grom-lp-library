# Starter: premium-editorial

Single-file, fully filled landing page assembled from the `reference/lp-library` block library on the **premium-editorial** theme (`themes/premium-editorial.css`, clay/charcoal, higher-ticket, editorial serif display, generous rhythm, prominent dark closing band). Block order: `hero-split -> offer-card -> why-us -> founder -> reviews -> how-it-works -> booking-widget -> faq-accordion -> sticky-cta -> footer`. The `_contract.css` + `premium-editorial.css` tokens are inlined into one `<style>` in the document head (contract first, theme second so it overrides). The hosted-loader head-tracking snippet sits at the very top of the file inside a single HTML comment, ready to paste into the page's tracking code settings.

**Sample identity (fictional, AHPRA-safe):** Maison Dermal, an aesthetic studio in South Yarra VIC, led personally by Dr. Elena Vasquez (MBBS), 5.0 from 96 reviews, treatments from $390, `CLIENT_KEY = "maison-dermal"`. The Meta Pixel ID is the literal placeholder `REPLACE_WITH_PIXEL_ID` (marked inline), the booking-worker URL is the placeholder `https://your-booking-worker.invalid` (marked inline, using the IANA-reserved `.invalid` TLD so it is unregistrable), and both hero/founder photos are placeholder SVG data URIs (marked inline) standing in for real clinic photography.

**Price handling:** unlike the clinical-trust starter (complimentary consultation only, no price), this is an aesthetic studio with a stated starting price. Both `hero-split` and `offer-card` `{{offer_price}}` slots are filled with "From $390." The consultation itself is framed as complimentary, with the $390 attached to the treatment rather than the conversation, so no AHPRA-sensitive outcome or results language is implied by the number. Copy avoids outcome guarantees and words like "permanent" or "cure," and keeps the "results" framing to process ("nothing is left unchecked") rather than promised effects.

**Dark-band treatment:** the theme's `--band-dark-bg`/`--band-dark-ink` tokens (deep charcoal `#241f1a` on warm cream `#f4e9dc`) drive the closing `footer` block, which is the only block in the library that consumes the dark-band tokens. Combined with the theme's serif display face, wider `--space-section` rhythm, and squared-off `--radius`/`--btn-radius` (2px), the footer reads as a deliberate, prominent close to the editorial page rather than a throwaway utility bar.

**To reuse for a real client:** clone this folder, run the FILL-GUIDE against the new client's identity, then swap the three placeholders: `CLIENT_KEY` in the head-tracking comment, `REPLACE_WITH_PIXEL_ID` with the client's real Meta Pixel ID, and the booking-worker URL with the client's real `grom-booking-worker` deployment, then replace the placeholder images with real photography.
